## 🌟 Key Features

- ⚡ **1-Click Multi-Platform Launcher**: Open LinkedIn, X (Twitter), Facebook, Instagram, Threads, YouTube, TikTok, Reddit, Bluesky, Pinterest, Discord, and GitHub in synchronized browser tabs.
- 🔍 **Brand & Handle Cross-Auditor**: Audit any creator or corporate handle (`@username`) across all major social networks simultaneously to check brand consistency, broken links, or profile availability.
- 🌐 **Live Web Application**: Access instantly from any device via [jtgsystems.github.io/socialmedia](https://jtgsystems.github.io/socialmedia/).
- 🖥️ **Cross-Platform CLI & Native Scripts**:
  - **Windows**: Updated `Social Media checkup.bat` with interactive menus and modern HTTPS endpoints.
  - **Linux & macOS**: Zero-dependency `social-media-launcher.sh`.
  - **Python Global CLI**: `socialmedia` command line dispatcher.

## 🚀 Quick Start

### 1. Live Web App (No Installation Needed)
Visit **[https://jtgsystems.github.io/socialmedia/](https://jtgsystems.github.io/socialmedia/)** directly in your browser.

### 2. Python CLI (Global Terminal Tool)
```bash
git clone https://github.com/jtgsystems/socialmedia.git
cd socialmedia
pip install -e .

# Launch all platforms:
socialmedia all

# Launch business channels (LinkedIn, X, FB, IG, Threads):
socialmedia business

# Audit a specific company handle across all networks:
socialmedia audit jtgsystems
```

### 3. Linux & macOS Native Script
```bash
./social-media-launcher.sh
```

### 4. Windows Native Script
Double-click `Social Media checkup.bat` or run in CMD:
```cmd
"Social Media checkup.bat"
```
